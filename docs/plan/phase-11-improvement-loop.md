# Phase 11: Evidence-based improvement loop

Close the coaching loop by rigorously measuring whether deliberate practice on specific weaknesses translates into measurable error reduction in subsequent real games.

## Deliverables

- Statistical baseline calculation per weakness using normalized error rates (mistakes per 100 moves) across historical game windows.
- Longitudinal comparison engine contrasting pre-practice baseline rates against post-practice performance in new games.
- Sample-size and statistical confidence indicators ensuring trends are not claimed on insufficient game data.
- Correlation tracking comparing puzzle practice success with subsequent in-game mistake reduction for practiced themes.
- Dynamic training priority adjustment elevating weaknesses that persist in recent games despite practice.
- Progress Report dashboard presenting observed changes with clear methodology notes (avoiding false causal claims).

## Demo

Review the Progress dashboard showing your pre-training baseline error rate for "Hanging Pieces", observe the error rate trend line over subsequent games, and see updated practice recommendations reflecting your real progress.

## Acceptance checks

- All mistake rates are strictly normalized per 100 moves (never raw mistake counts).
- Sample size requirements must be met before displaying trend directions; insufficient data states are explicitly communicated.
- Practice recommendations adapt based on both puzzle accuracy and subsequent game performance.
- Reports clearly state observed statistical changes without claiming unverified causal attribution.
