# Phase 7: Plug-and-play for other people

## Deliverables

- Spring Security with simple local accounts.
- `user_id` filtering on every query.
- Onboarding flow: username, waiting screen, and dashboard.
- Fair job scheduling across users.
- Per-user rating-band calibration.

## Acceptance checks

- A second user onboards with no manual steps.
- Tests cover that user A can never read user B's data.
