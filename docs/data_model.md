# Data Model

All tables are created and owned by Flyway migrations in `api/src/main/resources/db/migration/`.
The worker reads and writes rows but never runs DDL.

## Conventions

- Primary keys are UUIDs generated by the application layer (`gen_random_uuid()` default).
- All timestamps are `timestamptz` stored in UTC.
- Snake_case for all table and column names.
- Soft deletes are not used; rows are deleted or superseded by new rows.

## Tables

### users
Represents a registered user of the application. Multi-user ready from day one even though
auth is not enforced until Phase 7.

| Column              | Type        | Notes                                  |
|---------------------|-------------|----------------------------------------|
| id                  | uuid PK     | `gen_random_uuid()`                    |
| chesscom_username   | text UNIQUE | The chess.com account to import from   |
| display_name        | text        |                                        |
| rating_band         | int nullable | Approximate rapid rating; used for level-aware feedback |
| created_at          | timestamptz | `now()`                                |

### service_heartbeats
Written by each worker instance every few seconds. The Status page reads this to show whether
the worker is alive.

| Column      | Type        | Notes                               |
|-------------|-------------|-------------------------------------|
| service     | text PK (composite) | e.g. `worker`              |
| instance    | text PK (composite) | e.g. hostname or UUID      |
| last_seen   | timestamptz |                                     |
| details     | jsonb       | Arbitrary metadata (Ollama reachable, current job, etc.) |

### games
One row per imported game. The unique constraint prevents duplicates on re-sync.

| Column           | Type        | Notes                                      |
|------------------|-------------|--------------------------------------------|
| id               | uuid PK     |                                            |
| user_id          | uuid FK     | → users.id                                 |
| source           | text        | Default `chesscom`; `pgn_upload` for manual |
| external_id      | text        | chess.com game UUID (from URL/PGN)         |
| url              | text        |                                            |
| pgn              | text        | Full PGN including clock comments          |
| played_at        | timestamptz |                                            |
| time_class       | text        | `rapid`, `blitz`, `bullet`, `daily`        |
| time_control     | text        | e.g. `600`, `180+2`                        |
| user_color       | text        | `white` or `black`                         |
| result           | text        | `win`, `loss`, `draw`                      |
| termination      | text        | e.g. `resigned`, `checkmated`, `timeout`   |
| user_rating      | int         |                                            |
| opp_rating       | int         |                                            |
| opp_username     | text        |                                            |
| eco              | text        | ECO code from PGN header                   |
| opening_name     | text        | From PGN header                            |
| analysis_status  | text        | `none`, `queued`, `running`, `done`, `failed` |

Unique: `(user_id, source, external_id)`  
Index: `games(user_id, played_at DESC)`

### moves
Created by the worker during analysis. One row per half-move (ply).

| Column            | Type    | Notes                              |
|-------------------|---------|------------------------------------|
| id                | uuid PK |                                    |
| game_id           | uuid FK | → games.id                         |
| ply               | int     | 1-based; odd = White, even = Black |
| color             | text    | `white` or `black`                 |
| san               | text    | Standard algebraic notation        |
| uci               | text    | UCI move string e.g. `e2e4`        |
| fen_before        | text    | FEN before this move               |
| fen_after         | text    | FEN after this move                |
| clock_ms_remaining| bigint  | Milliseconds remaining on clock    |
| time_spent_ms     | bigint  | Milliseconds spent on this move    |

Unique: `(game_id, ply)`  
Index: `moves(game_id, ply)`

### analysis_runs
Records the exact engine settings used for an analysis. Allows re-running with different
settings and comparing results without overwriting history.

| Column         | Type        | Notes                              |
|----------------|-------------|------------------------------------|
| id             | uuid PK     |                                    |
| game_id        | uuid FK     | → games.id                         |
| engine_name    | text        | From UCI `id name` response        |
| engine_version | text        | Parsed from engine_name            |
| depth          | int         | Analysis depth per position        |
| multipv        | int         | Number of lines evaluated          |
| status         | text        | `running`, `done`, `failed`        |
| created_at     | timestamptz |                                    |

### move_evals
Engine evaluation for each move. All values are from the mover's perspective (positive = good
for the side about to move). Never mix with White-perspective values.

| Column              | Type    | Notes                                             |
|---------------------|---------|---------------------------------------------------|
| id                  | uuid PK |                                                   |
| run_id              | uuid FK | → analysis_runs.id                                |
| move_id             | uuid FK | → moves.id                                        |
| eval_before_cp      | int     | Centipawns before the move (mover's POV)          |
| eval_after_cp       | int     | Centipawns after the move (mover's POV)           |
| mate_before         | int     | Moves to mate before (null if none)               |
| mate_after          | int     | Moves to mate after (null if none)                |
| best_uci            | text    | Engine's best move                                |
| best_eval_cp        | int     | Eval of best move                                 |
| second_best_eval_cp | int     | Eval of second-best move (from multi-PV)          |
| pv_json             | jsonb   | Full principal variation lines                    |
| win_pct_before      | numeric | Win probability before move (0–100)               |
| win_pct_after       | numeric | Win probability after move (0–100)                |
| win_pct_loss        | numeric | Drop in win probability caused by this move       |
| classification      | text    | `book`, `best`, `good`, `inaccuracy`, `mistake`, `blunder` |

### mistakes
Derived from move_evals; represents a meaningful error by the user or a missed opportunity
when the opponent blundered.

| Column           | Type     | Notes                                         |
|------------------|----------|-----------------------------------------------|
| id               | uuid PK  |                                               |
| game_id          | uuid FK  | → games.id                                    |
| user_id          | uuid FK  | → users.id (denormalized for fast queries)    |
| move_eval_id     | uuid FK  | → move_evals.id                               |
| kind             | text     | `mistake` or `missed_opportunity`             |
| type             | text     | See mistake_types doc                         |
| tags             | text[]   | e.g. `time_pressure`, `endgame`               |
| phase            | text     | `opening`, `middlegame`, `endgame`            |
| severity         | numeric  | win_pct_loss value                            |
| material_swing_cp| int      | Material change in centipawns                 |

Index: `mistakes(user_id, type)`

### puzzles
One puzzle per qualifying mistake. FEN-deduplicated. Can also come from Lichess (Phase 8).

| Column            | Type     | Notes                                         |
|-------------------|----------|-----------------------------------------------|
| id                | uuid PK  |                                               |
| user_id           | uuid FK nullable | null = global puzzle                  |
| source            | text     | `own_game` or `lichess`                       |
| source_mistake_id | uuid FK nullable | → mistakes.id                        |
| fen               | text     | Starting position (before user's error)       |
| side_to_move      | text     | `white` or `black`                            |
| solution_uci      | text[]   | Ordered list of UCI moves                     |
| themes            | text[]   | e.g. `hanging_piece`, `fork`                  |
| difficulty_est    | numeric  | Estimated difficulty (0–1)                    |
| active            | boolean  | Whether this puzzle is shown to users         |

Index: `puzzles(user_id, active)`

### puzzle_attempts
One row per solve attempt.

| Column       | Type        | Notes                           |
|--------------|-------------|---------------------------------|
| id           | uuid PK     |                                 |
| puzzle_id    | uuid FK     | → puzzles.id                    |
| user_id      | uuid FK     | → users.id                      |
| solved       | boolean     |                                 |
| moves_tried  | jsonb       | Array of UCI moves the user played |
| time_ms      | int         | Time taken in milliseconds      |
| hints_used   | int         |                                 |
| attempted_at | timestamptz |                                 |

### review_schedule
Leitner-box spaced repetition schedule. One row per (puzzle, user) pair.

| Column      | Type        | Notes                           |
|-------------|-------------|---------------------------------|
| puzzle_id   | uuid PK/FK  | Composite PK with user_id       |
| user_id     | uuid PK/FK  |                                 |
| box         | int         | Leitner box number (1–5)        |
| due_at      | timestamptz | Next review time                |
| last_result | boolean     | Whether the last attempt succeeded |
| streak      | int         | Consecutive correct answers     |

Index: `review_schedule(user_id, due_at)`

### game_reviews
Stores the LLM-generated review. Unique per (game, model, prompt_version) so reviews can be
regenerated and compared without losing history.

| Column           | Type        | Notes                                         |
|------------------|-------------|-----------------------------------------------|
| id               | uuid PK     |                                               |
| game_id          | uuid FK     | → games.id                                    |
| run_id           | uuid FK     | → analysis_runs.id                            |
| model            | text        | Ollama model name e.g. `qwen3:8b`             |
| prompt_version   | text        | e.g. `v1`                                     |
| facts_json       | jsonb       | The structured facts passed to the LLM        |
| review_json      | jsonb       | Structured output from the LLM                |
| review_text      | text        | Human-readable prose summary                  |
| validation_status| text        | `ok` or `flagged`                             |
| created_at       | timestamptz |                                               |

Unique: `(game_id, model, prompt_version)`

### analysis_jobs
The job queue. Workers claim rows using `SELECT ... FOR UPDATE SKIP LOCKED`.

| Column      | Type        | Notes                                            |
|-------------|-------------|--------------------------------------------------|
| id          | uuid PK     |                                                  |
| user_id     | uuid FK     | → users.id                                       |
| game_id     | uuid FK nullable | → games.id                                  |
| kind        | text        | `analyze_game`, `generate_puzzles`, `review_game` |
| status      | text        | `pending`, `running`, `done`, `failed`           |
| attempts    | int         | Number of attempts so far                        |
| max_attempts| int         | Default 3                                        |
| locked_by   | text        | Worker instance identifier                       |
| locked_at   | timestamptz | When the job was claimed                         |
| last_error  | text        | Last failure message                             |
| payload     | jsonb       | Job-specific data                                |
| created_at  | timestamptz |                                                  |
| started_at  | timestamptz |                                                  |
| finished_at | timestamptz |                                                  |

Partial index: `analysis_jobs(status) WHERE status = 'pending'`

### service_heartbeats
See above. Primary key is `(service, instance)`.

## Migration Naming

```
V1__init.sql          — users, service_heartbeats
V2__games.sql         — games
V3__analysis.sql      — moves, analysis_runs, move_evals, mistakes
V4__puzzles.sql       — puzzles, puzzle_attempts, review_schedule
V5__reviews.sql       — game_reviews
V6__jobs.sql          — analysis_jobs
```

Never edit an applied migration. Always add a new one.
